# 제품 설계서 — 소부대 은밀 전술 단말 (2026-10-11 확정안)

> 사용자와 아이디에이션으로 확정한 내용. 이후 구현의 기준. 바뀌면 이 문서부터 고친다.

## 0. 한 줄 정의
**총을 놓지 않고, 전파를 숨긴 채, 분대 전체가 같은 적을 보고 같은 명령을 받는다.**
GPS·인터넷 없이도 분대가 돌아가고, 인터넷은 꼭 필요한 순간에만 짧게 쓴다.

## 1. 원칙
1. **메인은 단말, 폰은 보조.** 단말이 없으면 아무것도 안 되고, 폰이 없어도 분대 통신은 된다.
2. **모두 동등.** 분대장·분대원 구분 없음. 대원마다 "단말 + 아이폰" 한 쌍.
3. **겨누는 건 총(단말).** 폰은 GPS 정보용. 폰 나침반은 쓰지 않는다.
4. **보안 = 내용(암호화) + 위치(전파 통제).** 암호화는 무엇을 말했는지, 전파 통제는 어디서 말했는지를 숨긴다.
5. **화면은 저절로 바뀌지 않는다.** 들어온 메시지는 작은 표시(✉)와 LED만. 보고 싶을 때 버튼으로 꺼내 본다.

## 2. 구성
| 구성 | 장치 | 역할 |
|---|---|---|
| 대원 단말 | NU-40 DK + IMU + OLED + 배터리 | 겨눈 방향(자이로), 버튼 보고, 분대 방송 송수신, 메시지 표시 |
| 대원 폰 | 아이폰 (비행기 모드 + 블루투스만) | GPS를 단말에 공급, 메시지 작성·열람, 지도, 키 로더 |
| 후방 기지국 | NU-87 TinyDK (+ 스타링크 와이파이) | 분대 방송 청취, 허용된 경우에만 인터넷으로 중앙에 1건 보고 |
| 중앙 지휘소 | 서버 + 웹 기록판 | 교전·구조·의도적 보고 기록, 대기 명령 보관 |

## 3. 단말 버튼과 화면

| 버튼 | 누르는 법 | 동작 | 인터넷(중앙) |
|---|---|---|---|
| **S4 적 발견** | 1번 | 적 발견 · **사격 개시** (위치 + 겨눈 방향) | ✅ |
| | 2번 | 적 발견 · **사격 금지** (은밀 유지) | ❌ 분대만 |
| | 카운트다운 중 3번 | **취소** (안 보냄) | – |
| **S3 긴급 구조** | 1번 | 구조 요청 (위치 포함) | ✅ |
| | 카운트다운 중 3번 | **취소** | – |
| **S2 메시지** | 1번 | 최근 **동료** 메시지 보기 | – |
| | 2번 | 최근 **중앙** 메시지 보기 | – |
| **S1 확인** | 짧게 | 메시지 보는 중 → **수신 확인** / 평소 → **이상 없음** | ❌ |
| | 3초 | **방향 기준 맞추기** (분대가 같은 방향을 보고 동시에) | – |

**3초 카운트다운 규칙 (S4·S3 공통)**
- 누른 횟수는 마지막 누름 후 약 0.6초 뒤 확정 → 바로 전송하지 않고 **3초 카운트다운**.
- 화면: `OPEN FIRE 3…2…1  S4x3=CANCEL` / `HOLD FIRE …` / `SOS …`
- 카운트다운 중 **같은 버튼 3번 = 취소**(안 보냄). 그대로 두면 3초 뒤 전송.
- **이미 전송된 뒤** 같은 동작을 하면 **"정정: 잘못 봤음"**을 분대에(중앙에 올라간 보고면 중앙에도) 보낸다.

**화면**
- 평소: 상대 거리(구간 표시), 연결 상태, 내 호출부호(E-1 등), 방향 각도, 안 읽은 메시지 표시(✉ 동료 n · 중앙 n)
- 적 발견 수신: `ENEMY · FROM E-2 · OPEN/HOLD` + 적 방향 화살표 (내가 돌면 화살표도 돈다)
- 메시지: 한글(Galmuri11), 띄어쓰기 줄바꿈, 4줄 넘으면 스크롤, S1로 수신 확인
- 내 보고가 중앙에 올라가면 `#N 중앙 전달됨 ✅`

**거리 표시 개선**
- 블루투스 신호 세기는 방향·주변 물체로 15dB 이상 흔들려 정밀 거리 불가(5cm가 0.8m로 표시된 사례).
- 숫자 대신 **구간**: `붙어 있음 / 1m 이내 / 약 2m / 약 5m / 10m 이상`
- 안테나 내장형 두 보드 기준으로 0.5·1·2·4m 재측정해 기준값 보정.

## 4. 통신 규칙

**분대 안 (블루투스 방송, 인터넷 X)**
- 단말끼리 근거리 방송으로 위치·방향·보고·메시지를 주고받는다(연결 없는 1:N 방송, 몇 명이든 동시 수신).
- 폰 ↔ 자기 단말은 1:1 보안 연결. 아이폰은 제조사 데이터 방송이 불가하므로 반드시 자기 단말을 거친다.
- 폰은 몇 초마다 GPS를 단말에 넣어 둔다 → 버튼을 누르는 순간 단말이 "최신 위치 + 겨눈 방향"을 바로 방송(폰이 잠깐 끊겨도 마지막 위치 + 경과 시간).

**분대 → 중앙 (인터넷은 딱 이 세 경우만)**
1. **교전**: S4 1번(사격 개시) 확정
2. **긴급 구조**: S3 확정
3. **의도적 전송**: 폰 앱에서 "중앙에 보냄"을 고른 메시지
- NU-87이 해당 방송을 들으면 **그때만 와이파이를 켜고 → 스타링크 → mTLS 1건 → 와이파이 끔**(접속 포함 약 5~10초, 추정).
- **사격 금지 발견은 올리지 않는다**(은밀 유지 중 송신은 존재를 드러냄).

**중앙 → 분대 (답장에 실어서만)**
- 위 업로드의 **답장으로 쌓여 있던 명령을 받아 온다.** 따로 연결하지 않는다.
- NU-87이 받은 명령을 분대에 방송 → 단말에는 ✉ 표시만, S2 2번으로 열람, S1로 수신 확인.
- 업로드 성공 시 `#N 중앙 전달됨`을 방송 → 보낸 사람 화면에 ✅.

**중앙 지휘소는 실시간 상황판이 아니다**
- 받는 것: 교전 보고(보고자 위치·적 방향·사격 개시), 구조 요청(위치), 의도적 메시지, 정정.
- 기록판: 시각순 목록 + 지도에 보고자 위치와 적 방향선, **두 명 이상 보고 시 방향선 교차 = 적 추정 위치**.
- 평소 대원 위치는 상급에 올라가지 않는다.

## 5. 보안

| 구간 | 위험 | 대책 | 시연·증명 |
|---|---|---|---|
| 폰 ↔ 단말 | 가짜 폰 접속, 도청 | 블루투스 보안 페어링(LESC) — **단말 OLED 6자리 숫자를 폰에 입력**, 짝지은 폰만 연결 | 숫자 입력 화면 / 짝 안 지은 폰(nRF Connect)은 "인증 필요"로 거절 |
| 단말 ↔ 단말 (방송) | 내용 노출, 가짜 명령, 녹음 재생 | **분대 공용 열쇠 AES-128** 암호화 + **인증 태그**(위조 차단) + **카운터**(재생 차단) | nRF Connect로 보면 무작위 바이트 / NU-87을 공격자로 바꿔 위조·재생 → 단말에 "위조 거부 N건" |
| NU-87 ↔ 중앙 | 스타링크 구간 도청·위장 | **mTLS**(서로 인증서 확인 + 암호화). 단말 암호는 NU-87에서 풀지 않고 중앙까지(종단 간) | 패킷 캡처에 평문 없음 / 인증서 없는 장치는 서버가 거절 |

- **키 로더 = 폰**: 작전 전에 분대 열쇠를 **QR로 대면 전달** → 폰이 보안 연결로 자기 단말에 장전. 전파로 열쇠를 보내지 않는다(군 무전기 키 로더 원칙). 작전 중에는 폰 없이 단말끼리 암호 통신.
- **단말 탈취 시**: 남은 대원이 새 열쇠로 재장전 → 탈취 단말은 읽기·쓰기 불가.
- **위치 노출(전파 통제)**: 분대 안은 약한 블루투스만, 인터넷은 세 경우만 짧게, 송신 지점(스타링크·NU-87)은 분대와 떨어진 후방.
- 방송 크기: 26바이트 한도 안에 [표시 2 + 보낸 이 1 + 카운터 3 + 암호화된 내용(이벤트·배터리·방향·확인번호·위도·경도) + 태그 4]. 세부 배치는 구현 때 확정.
- VPN은 폰(WireGuard)에 적용 가능하나 이번엔 채택하지 않음. NU-87은 mTLS로 충분(연결 하나만 보호하므로 탈취 시 피해 범위가 좁음).

## 6. 아이폰 앱 (Xcode, CoreBluetooth)
- **GPS 공급**: 몇 초마다 자기 단말에 위치 전달
- **보안 페어링 + 키 로더(QR)**
- **메시지**: 작성 → 단말 경유 분대 방송 / "중앙에 보냄" 선택 시 중앙 업로드 대상 / 받은 메시지 열람
- **지도**: 동료 위치, 적 방향선, 교차 추정 위치 (실내는 GPS 불안정 → 시연용 수동 위치 지정 모드)
- 폰 나침반으로 겨누기는 하지 않음(겨누는 건 단말)

## 7. 구현 순서와 상태
| 순서 | 항목 | 상태 |
|---|---|---|
| 1 | 단말 버튼 체계(S1~S4, 카운트다운·취소·정정), 메시지 표시 정책(✉), 거리 구간 표시 | 새로 (보드만, 금방) |
| 2 | 방송에 위치 싣기 + 방송 암호화·카운터 + 위조·재생 공격 시연 | ✅ 암호화·인증·재생방지 완료(하드웨어 검증). 위치(GPS) 싣기는 폰 GATT 후 |
| 3 | NU-87: 해당 방송 때만 와이파이 → mTLS 업로드 → 답장 명령 → 분대 방송, 전달 확인 | 새로 (메시지 조각 방송은 일부 완성) |
| 4 | 중앙 서버 + 교전 기록판 (상황판 pane에 화면 성격 변경 요청) | 새로 |
| 5 | 아이폰 앱 (GPS, 페어링·키 로더, 메시지, 지도) | 새로 (가장 큼) |
| 6 | 발표 자료·시연 순서 | 마지막 |

이미 된 것: 단말 간 방송·거리·배터리, 자이로 방향(드리프트 해결), 적 방향 화살표, 한글 메시지 표시·수신 확인, NU-87 수신·와이파이·자동 복구, 버튼 없는 업로드, 하드웨어 구성도.
